# 🍩 ASCII Donut C
## 🎬 Demo

[▶ Watch the ASCII Donut animation](demo.mp4)

A rotating 3D ASCII donut rendered directly in the terminal using **C**.

This project explores the fundamentals of 3D graphics, including mathematical rotation, perspective projection, depth buffering, and ASCII shading — all without graphics libraries.

## ✨ Features

- Real-time 3D donut animation
- X-axis and Y-axis rotation
- Perspective projection
- Z-buffer depth handling
- ASCII-based lighting and shading
- Lightweight implementation using standard C libraries

## 🛠️ Built With

- C
- GCC
- `math.h`
- Windows Terminal / VS Code Terminal

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ApexPraxis/ASCII-Donut-C.git
cd ASCII-Donut-C
```

### 2. Compile

```bash
gcc ./src/main.c -o donut.exe -lm
```

### 3. Run

```bash
./donut.exe
```

Press `Ctrl + C` to stop the animation.
